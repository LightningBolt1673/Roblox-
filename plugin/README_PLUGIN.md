Plugin: hello.plugin.lua

This is a minimal Studio plugin that inserts a part called `InsertedByPlugin` into `Workspace`.

To use locally:
- On Windows, save the `.lua` file into `%LocalAppData%\Roblox\Plugins\` and restart Studio.
- On macOS, place the plugin in `~/Library/Application Support/Roblox/Plugins/` (or use Studio's plugin manager).

Alternatively, install the plugin via the Developer Hub by packaging it in Roblox and installing from Toolbox if you publish the plugin.
