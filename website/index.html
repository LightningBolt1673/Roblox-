Roblox-

A small Roblox project scaffold with Rojo support, example scripts, and a plugin stub.

Explore features Get started

Included

  • Rojo mapping: default.project.json
  • Server scripts: leaderstats, coin spawner
  • Client scripts: welcome GUI, leaderboard UI
  • Studio plugin stub: plugin/hello.plugin.lua
  • Pasteable snippets in snippets/

How to run locally

Recommended: use Rojo to manage code and sync with Roblox Studio.

  1. Install Rojo: npm install -g @rojo/core (or follow Rojo docs).
  2. Build a `.rbxlx` from the project root: rojo build -o RobloxProject.rbxlx
  3. Open the produced `RobloxProject.rbxlx` in Roblox Studio, or run rojo serve and use the Rojo Studio plugin for live sync.

Quick paste

If you prefer not to use Rojo, copy the scripts from snippets/ into Studio:

  • Server: paste into ServerScriptService
  • Client: paste into StarterPlayer > StarterPlayerScripts

Deployment

This repository includes a GitHub Actions workflow to publish the static site to the gh-pages branch. Enable GitHub Pages in the repository settings (source: gh-pages branch) after the workflow runs.
